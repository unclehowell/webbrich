# Webb–Rich Family Archive — Over Stowey

Documentary wiki of the Rich family of Over Stowey, Somerset: people, manors, landholding, title, tithe, evidence and estate contraction.

Live site: https://webbrich.bucklerfamily.estate/

- `main` — the live site (Cloudflare Pages production branch). Static: `index.html` at the root, no build step.
- `webbrich` — same content as `main`, kept for continuity with the original branch name.
- Section branches (e.g. `ebooks`, `research`) — placeholders for future sections of this archive.
